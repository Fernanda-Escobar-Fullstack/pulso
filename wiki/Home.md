# pulso Documentation

pulso is a web application intended to help small and medium-sized gastronomic businesses understand product costs, margins, ingredient-price changes, purchases, and, over time, other operational information.

This Wiki is the detailed documentation entry point for product, domain, UX, engineering, AI, quality, operational, decision, and project knowledge.

## Documentation status

Documentation will evolve as the project progresses. Pages marked **Not defined yet** are placeholders only and do not represent approved product or technical decisions.

## Core principle

Critical financial and inventory calculations should be deterministic and verifiable. AI should operate as an assistance and interpretation layer rather than as the source of truth for financial calculations.
